# Questão 08 – Cadastro de Estudantes

Lista de Exercício 01 – React Native · Desenvolvimento para Dispositivos Móveis (UFRA)

## Descrição
Cadastra estudantes (objetos em um array) e exibe cards com `map()`.

## Como usar
Preencha nome, matrícula, e-mail e curso e toque em **Cadastrar**. Todos os campos são obrigatórios e matrículas duplicadas são recusadas. Use **Remover** no card para excluir.

**Exemplo:** `{ nome: "Maria Silva", matricula: "20260001", email: "maria@exemplo.com", curso: "Licenciatura em Computação" }`

## Tecnologias
React Native com Expo (componentes `View`, `Text`, `TextInput`, `StyleSheet` e o hook `useState`).

## Como executar
```bash
npm install
npx expo start
```
Escaneie o QR Code com o app **Expo Go** no celular (Android ou iOS).  
Também é possível colar o conteúdo de `App.js` em https://snack.expo.dev para testar no navegador.
