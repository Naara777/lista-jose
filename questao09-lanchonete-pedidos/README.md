# Questão 09 – Lanchonete Universitária

Lista de Exercício 01 – React Native · Desenvolvimento para Dispositivos Móveis (UFRA)

## Descrição
Monta pedidos de uma lanchonete com subtotais, total e resumo final.

## Como usar
Toque em **+1** para adicionar um produto ao pedido (cada toque soma uma unidade). Os itens (objetos em um array) aparecem no resumo com subtotal e o total é calculado na hora; **Remover** tira o item.

**Exemplo:** 2 sanduíches de R$ 8,00 + 1 suco de R$ 5,00 → R$ 21,00

## Tecnologias
React Native com Expo (componentes `View`, `Text`, `TextInput`, `StyleSheet` e o hook `useState`).

## Como executar
```bash
npm install
npx expo start
```
Escaneie o QR Code com o app **Expo Go** no celular (Android ou iOS).  
Também é possível colar o conteúdo de `App.js` em https://snack.expo.dev para testar no navegador.
