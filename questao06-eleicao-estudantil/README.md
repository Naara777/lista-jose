# Questão 06 – Eleição Estudantil

Lista de Exercício 01 – React Native · Desenvolvimento para Dispositivos Móveis (UFRA)

## Descrição
Registra votos para três candidatos fictícios, mostrando totais, o mais votado e empates.

## Como usar
Toque no botão de cada candidato (Ana, Bruno e Carla) para votar. O total geral e o mais votado (ou empate) são atualizados na hora.

**Exemplo:** 10, 15 e 8 votos → segundo candidato mais votado

## Tecnologias
React Native com Expo (componentes `View`, `Text`, `TextInput`, `StyleSheet` e o hook `useState`).

## Como executar
```bash
npm install
npx expo start
```
Escaneie o QR Code com o app **Expo Go** no celular (Android ou iOS).  
Também é possível colar o conteúdo de `App.js` em https://snack.expo.dev para testar no navegador.
